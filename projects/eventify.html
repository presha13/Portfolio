Eventify

Billing & Business Management Platform for Event Companies

React 18 Vite Tailwind CSS React Router Recharts Vercel

Overview

Built and deployed a React web app that lets event-management businesses run their day-to-day operations: invoices, quotations, events, expenses and financial-year reporting. It talks to a REST backend with secure cookie-based sessions and server-side PDF generation, and is live on Vercel.

Live Demo View Code

Key Features

  • Billing: Invoices with discounts and free items, payment status tracking, bill merging and bulk PDF export.
  • Quotations: Create, track and convert quotations into bills (and back) in one click.
  • Authentication: HttpOnly cookie sessions, protected routes, password reset and 30-minute inactivity logout.
  • Financial Years: All data scoped by financial year, with automatic selection of the current period.
  • Operations: Event calendar, expense tracking, product library and an analytics dashboard.
  • Productivity: Voice input for line items and Alt-key shortcuts for fast navigation.
  • Resilience: API client retries automatically while the backend wakes up from a cold start.

# Eventify Frontend React client for the Eventify billing platform, built with Vite and Tailwind CSS. ## Quick Start 1. npm install 2. Create .env.local with VITE_API_BASE_URL=http://localhost:5001/api 3. npm run dev ## Structure - src/components/ UI grouped by domain (Auth, Billing, Quotations, Events, Expenses, Dashboard) - src/services/ API client (cookie auth, retry on cold start) - src/contexts/ Auth and Financial Year providers ## Security - HttpOnly cookie sessions, no tokens in localStorage - Console logs and debuggers stripped from production builds - Route protection via ProtectedRoute ## Tech Stack React 18, Vite, Tailwind CSS, React Router, Recharts, Lucide icons, Vercel
