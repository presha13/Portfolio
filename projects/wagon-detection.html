Wagon Detection

Automated Wagon Number Recognition System

TensorRT Jetson Orin YOLOv11 Florence OCR CUDA

Overview

Built a real-time wagon number detection and telemetry extraction system deployed on resource-constrained embedded hardware (NVIDIA Jetson Orin, Xavier, and Nano). Optimized deep learning inference using TensorRT and CUDA with INT8/FP16 quantization. Integrated Microsoft Florence OCR for accurate text extraction from moving trains under continuous 1080p industrial streams.

Key Technologies

  • Hardware Target: NVIDIA Jetson Orin, Xavier, Nano (ARM64)
  • Inference Runtime: NVIDIA TensorRT (FP16/INT8), CUDA
  • Vision Models: YOLOv11 & Microsoft Florence OCR
  • Streaming & Processing: OpenCV, GStreamer, V4L2
  • Telemetry: Automated structured logging & CSV ingestion

README.md

# Wagon Detection System ## Pipeline 1. Capture continuous 1080p camera streams via GStreamer / V4L2 2. Detect wagons and number plates with a TensorRT-optimized YOLOv11 engine (FP16/INT8) 3. Extract wagon numbers with Microsoft Florence OCR 4. Write structured telemetry logs and CSV output for downstream tracking ## Features - Real-time detection on NVIDIA Jetson using TensorRT + YOLOv11 - High-accuracy OCR with Microsoft Florence - Automated CSV logging

Project Impact

This system significantly reduces manual effort in tracking railway wagons, minimizing human error and providing real-time data for logistics management. Running inference on the edge keeps the pipeline efficient and reliable in industrial environments.
